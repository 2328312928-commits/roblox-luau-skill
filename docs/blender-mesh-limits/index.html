Roblox mesh limits for Blender

Every limit Roblox applies to meshes you make in Blender, in one place. Copied from Roblox's creator documentation and checked on 2026-10-28; each section links to its source page.

Triangles are counted after Roblox converts quads, so a quad counts as 2. Roblox supports texture uploads up to 4096×4096 but lists 1024×1024 as the maximum texture map size; Marketplace accessory textures can't exceed 2048×2048.

Geometry rules

  • Watertight: no exposed holes or backfaces.
  • No n-gons: quads where possible.
  • Volume: meshes can't have zero thickness.
  • One material per mesh object, and a single UV set with all UVs inside 0–1 (overlaps are allowed).

Rigging

  • At most 4 bones influence any vertex.
  • Bones frozen: scale 1, 1, 1 and rotation 0, 0, 0. The root bone at 0, 0, 0 with no influences.
  • Only one animation track per exported mesh.

Cages (layered accessories)

Name the cages after the mesh: Shirt_InnerCage and Shirt_OuterCage for a mesh called Shirt. Don't delete cage vertices or change cage UVs.

Units and FBX export settings

  • Units: Scene Properties → Units → Unit System None, Rotation Degrees. Then 1 Blender unit = 1 stud when you import with Scale Unit set to Stud.
  • FBX export: Path Mode Copy with Embed Textures on; Transform → Apply Scalings FBX Unit Scale; Armature → Add Leaf Bones off; Bake Animation off unless you export an animation.
