Save-size checker

Paste a save as JSON (what HttpService:JSONEncode would produce) to see its size against the 4,194,304 limit. The page counts UTF-8 bytes, which is what Luau's # returns and never less than the character count, so it errs on the safe side.

Read the live budget in your game

local DataStoreService = game:GetService("DataStoreService")
for _, requestType in Enum.DataStoreRequestType:GetEnumItems() do
	print(requestType.Name, DataStoreService:GetRequestBudgetForRequestType(requestType))
end

Run it from a server Script. The budget refills over time, so check it before bursts of requests (for example a save on shutdown), and queue saves instead of firing them all at once.
