How the numbers work

Price of the next level is floor(baseCost × growth^owned). Rebirth k needs baseRequirement × requirementGrowth^k and multiplies income by 1 + k × multiplierPerRebirth. With an additive multiplier, each rebirth takes about growth × (1 + k·p) / (1 + (k+1)·p) times as long as the previous one, so it creeps towards requirementGrowth. A ratio around 1.2–1.5 keeps progress steady; 2+ means players hit a wall. Derivations: formulas.md.

Same maths as the command-line version (lune run scripts/balance.luau config.json), which is also a Claude skill for designing simulator economies: roblox-luau-skill on GitHub.
